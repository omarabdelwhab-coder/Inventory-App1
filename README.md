# 📦 Inventory Management System

A full-stack inventory management application designed to help businesses manage products, track stock, and organize inventory operations through a modern and user-friendly interface.

## 🚀 Technologies Used

### Frontend
- Angular
- TypeScript
- HTML5 & CSS3

### Backend
- Node.js
- Express.js
- RESTful APIs

### Database
- MongoDB
- Mongoose

### Desktop Application
- Electron

### Tools
- Git & GitHub
- Postman
- Visual Studio Code

## ✨ Features

- **Product Management:** Create, view, update, and delete products.
- **Inventory Tracking:** Manage product information and stock quantities.
- **RESTful API:** Backend services for handling inventory operations.
- **Database Integration:** Store and manage inventory data using MongoDB.
- **Desktop Support:** Electron integration for running the application as a desktop app.

## ⚙️ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/omarabdelwhab-coder/Inventory-App1.git
```

### 2. Install Backend Dependencies

```bash
cd server
npm install
```

### 3. Configure Environment Variables

Create a `.env` file inside the server directory:

```env
PORT=5000
MONGO_URI=your_mongodb_connection_string
```

### 4. Run the Backend

```bash
npm run dev
```

### 5. Run the Frontend

Open another terminal:

```bash
cd client
npm install
ng serve
```

Open your browser at:

```text
http://localhost:4200
```
